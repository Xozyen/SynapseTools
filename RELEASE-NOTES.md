# SynapseTools 1.2.1 — Combo editor

This release adds named repeat blocks, multi-step copying, a spell/movement timeline with input-free playback, and a shortcut for pausing movement around a spell. Spell selection can use uniquely matched names from the locally installed client. The floating panel displays the active step. Client diagnostics have moved under Advanced settings.

Existing profiles remain compatible; loading them does not rewrite their timings or bindings. Saving a profile backs up the preceding version.

Validation: automated sequence and editor checks passed on the packaged, obfuscated assembly. These checks do not establish live-game cast acceptance. Screen capture remains experimental. Automatic updating and license enforcement are not part of this release.
